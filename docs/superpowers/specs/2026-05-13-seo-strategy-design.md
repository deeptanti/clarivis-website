## 1. Core Architecture

Two layers that never mix.

**Core website** (`/solutions`, `/about`, `/assessment`, `/contact`) stays clean. Changes are technical only: sitemap fix, structured data additions, on-page metadata sharpening. No new pages, no SEO sprawl.

**`/insights` hub** is the SEO engine. Everything that ranks lives here: guides, articles, glossary terms, FAQs, news-grounded articles, comparison content, city-targeted articles, and cross-vertical cornerstones. The content machine feeds exclusively into `/insights`. Every piece links to a relevant `/solutions` page and to `/assessment`.

**The funnel:** search → `/insights` → `/solutions` → `/assessment` → booking.

## 3. Keyword Research Findings

Research conducted 2026-05-13. Key findings:

**Competition landscape:** Generic terms ("AI consulting India") dominated by TCS, Infosys, Wipro, Accenture, and mid-tier generalists (SparxIT, InnovationM, eSparkBiz). Direct competition on these terms is not viable in months 1-2.

**Real estate:** Fragmented competition. FlowAI, C0D3AI, TechAhead are SaaS products, not consulting firms. No strong player owns the consulting-positioned terms. "AI consulting for real estate developers India" and city-specific variants have genuine searches with weak content currently ranking.

**Healthcare:** SaaS layer is competitive (Voiceoc, Cliniify, TechWize, DoctorsApp own appointment-specific terms). The consulting gap is wide open. "AI consulting for multispecialty clinics India" and informational long-tail terms have no strong consulting-positioned content.

**Agribusiness: standout opportunity.** Entire agritech ecosystem targets smallholder farmers (CropIn, Fasal, DeHaat). Zero competition for "AI for managed farmland operators India", "agri-investment CRM India", "workforce management AI for agribusiness India". Clarivis can own this category from day one.

**Key differentiator in search:** Most results for vertical AI terms show SaaS products, not consulting firms. Positioning content as consulting-oriented (not product demos) is itself a gap worth exploiting across all three verticals.

## 4. Content Architecture

### Content types and distribution (10/day)

| Type | Per day | Per month | Word count | Purpose |
|---|---|---|---|---|
| Guide | 1 | 30 | 1,500–2,500 | Pillar authority, Tier 2 keywords |
| Article | 5 | 150 | 800–1,200 | Tier 3 long-tail, news-grounded |
| FAQ | 3 | 90 | 300–500 | Featured snippet targeting, Tier 3 |
| Glossary | 1 | 30 | 400–600 | Topical authority, internal linking anchors |

### Monthly content balance

Each week covers all three verticals. No vertical dominates. Rough weekly target:
- Real estate: 30% of output
- Healthcare: 30% of output
- Agribusiness: 30% of output
- Cross-vertical / generalist: 10%

### Month 1 focus
Tiers 2 and 3. Three vertical cornerstone guides published in Week 2. Long-tail article clusters build supporting topical authority. Glossary terms establish internal linking anchors. No Tier 1 generalist cornerstones yet.

### Month 2 focus
Tier 1 generalist cornerstones go live. Tier 4 comparison content. City-targeted articles under `/insights` (not separate pages). Increased internal linking density as the content library grows.

### Content rules (enforced by agent pipeline)
- Minimum 2 external grounding sources per piece, cited and hyperlinked inline
- Target keyword in title, first paragraph, and at least two H2s
- Every piece links to the relevant `/solutions/[vertical]` page
- Every piece ends with an Assessment CTA
- No em dashes anywhere
- Tone: sharp, authoritative, warm. Written for the Indian business owner, not the Silicon Valley engineer

## 5. AI Agent Content Pipeline

> **Note:** Implementation detail for this system is deferred to a separate design session and plan. This section captures the architecture at strategy level.

### Overview
A fully autonomous content and social media team deployed on Railway, orchestrated by n8n, running CrewAI agent crews backed by the Claude API.

### Infrastructure
```
Railway Project: clarivis-content-engine
├── n8n           (Docker: n8nio/n8n)      orchestration + cron scheduling
├── content-api   (FastAPI + CrewAI)       both crews live here
├── renderer      (Node + Puppeteer)       SVG → PNG for social graphics
└── PostgreSQL    (Railway native)         n8n internal database
```

### Crew 1: Content Crew (daily cron)
1. **Keyword Scout** — pulls today's targets from `keyword_queue` Supabase table
2. **News Hunter** — fetches Indian business RSS feeds (ET, Business Standard, Mint), triages for vertical relevance
3. **Research Analyst** — finds 2-3 grounding sources per piece via web search
4. **Content Writer** — writes the full piece with Claude, cites sources inline
5. **Publisher** — inserts to Supabase `content` table with `published = true`

### Crew 2: Social Crew (triggered per published article)
1. **Social Strategist** — determines platform angle per article
2. **Caption Writer** — LinkedIn caption (150-200 words, insight-led) + Instagram caption (punchy, 5-8 hashtags)
3. **Graphics Designer** — calls Claude API with full brand spec, receives SVG, renderer converts to PNG
4. **Scheduler** — queues posts via Postiz API

### Social graphic spec (embedded in Graphics Designer system prompt)
- Background: `#1A1A2E`
- Brand accent: `#0F6E56`
- Vertical accents: real estate = forest green + gold, healthcare = clinical blue, agribusiness = warm amber
- Fonts: DM Sans ExtraBold for headline, Roboto Regular for body
- Max three text elements per graphic
- Stat as largest element (min 80px equivalent)
- Logo bottom-left, small
- Output: 1080×1080 PNG (Instagram), 1200×627 PNG (LinkedIn)

### News sources (RSS, free)
- ET Real Estate: `economictimes.indiatimes.com/industry/services/property-/-cstruction/rssfeeds`
- ET Health: `health.economictimes.indiatimes.com/rss/topstories`
- ET Agri: `economictimes.indiatimes.com/industry/indl-goods/svs/agri-/-allied-indus/rssfeeds`
- Business Standard: `business-standard.com/rss/home_page_top_stories.rss`
- Mint: `livemint.com/rss/news`

### New Supabase table required
`keyword_queue` — keyword, tier (1-4), vertical, content_type, status (pending/in_progress/used), priority. Deep runs migration before pipeline goes live.

### Daily digest (Resend)
End-of-day email listing: pieces published (title, vertical, type, URL), social posts queued per platform, any errors or held pieces.

## 6. Technical SEO Fixes (Week 1)

Existing pages only. No new routes.

### Critical: Sitemap bug
`src/app/sitemap.ts` still lists `/services/real-estate`, `/services/healthcare`, `/services/agribusiness`. These routes no longer exist. The insights hub plan (Task 10) already includes the fix with an async Supabase-backed sitemap. This must ship before any content does.

### Structured data additions

**LocalBusiness schema** — add to `layout.tsx` alongside the existing Organization schema:
```json
{
  "@type": "LocalBusiness",
  "name": "Clarivis Intelligence",
  "address": {
    "@type": "PostalAddress",
    "addressLocality": "Rajkot",
    "addressRegion": "Gujarat",
    "addressCountry": "IN"
  },
  "url": "https://clarivisintelligence.com",
  "email": "hello@clarivisintelligence.com",
  "telephone": "+91-84018-14334"
}
```

**Service schema** — add to each `/solutions/[vertical]/page.tsx`:
```json
{
  "@type": "Service",

  "areaServed": "IN",
  "description": "[vertical description]"
}
```
